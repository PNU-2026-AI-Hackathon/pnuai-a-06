# 찌그까

> 여행 전·중·후를 연결하는 AI 기반 미션형 부산 관광 플랫폼

`찌그까`는 부산 관광의 지역 쏠림 문제를 완화하고, 2030 세대가 부산 여행을 더 쉽게 기록하고 공유할 수 있도록 돕는 모바일 앱 서비스입니다. 실시간 혼잡도, 장소별 사진 미션, AI 사진 분석, 개인화 타이틀, 동행자 전용 공유, AI 여행 매거진 생성을 하나의 여행 흐름으로 연결합니다.

<br/>

### 1. 프로젝트 소개

#### 1.1. 개발배경 및 필요성
부산 관광은 해운대, 광안리 등 일부 유명 관광지로 수요가 집중되는 문제가 있습니다. 주말과 성수기에는 동부산권 과밀화로 교통 체증과 환경 훼손이 발생하는 반면, 영도, 서구, 강서구, 기장 등 로컬 관광지는 충분한 매력을 가지고도 방문객이 적어 지역 상권 활성화에 어려움을 겪고 있습니다.

또한 2030 세대에게 여행은 단순 방문이 아니라 기록하고 공유하는 콘텐츠 경험입니다. 하지만 브이로그나 여행기 제작은 편집과 정리 과정이 복잡해 실제 행동으로 이어지기 어렵고, 공개 SNS에 올리는 방식은 평가 부담이 있습니다. 따라서 부산의 숨은 명소를 자연스럽게 방문하게 만들면서도, 촬영만으로 완성도 있는 여행 콘텐츠를 만들 수 있는 서비스가 필요합니다.

<br/>

#### 1.2. 개발 목표 및 주요 내용
본 프로젝트의 목표는 부산 여행을 `발견 -> 참여 -> 창작`의 경험으로 전환하여 관광 수요를 자발적으로 분산시키는 것입니다.

- 여행 전: 부산 지역별 혼잡도와 숨은 명소를 확인하고 맞춤 미션을 선택합니다.
- 여행 중: 현장에서 사진 미션을 수행하고 AI가 사진을 분석해 미션 달성 여부와 개인화 타이틀을 제공합니다.
- 여행 후: 동행자 반응, 방문 기록, 사진 분석 결과를 바탕으로 AI가 여행 매거진을 자동 생성합니다.

<br/>

#### 1.3. 세부내용
서비스 핵심 흐름은 다음과 같습니다.

1. 사용자가 부산 내 관광 지역을 선택합니다.
2. 지도에서 관광 스팟별 혼잡도를 `여유`, `보통`, `혼잡` 3단계로 확인합니다.
3. 장소, 시간대, 계절에 맞는 사진 미션을 선택합니다.
4. 현장에서 미션 사진을 촬영하고 업로드합니다.
5. AI가 사진의 피사체, 구도, 색감, 분위기, 장소 맥락을 분석합니다.
6. GPS, 촬영 시간, 미션 조건을 함께 검증하여 미션 달성 여부를 판단합니다.
7. 사용자는 `영도 골목길 탐험가`, `다대포 석양을 담은 감성 사진가`와 같은 개인화 타이틀과 뱃지를 획득합니다.
8. 여행 종료 후 AI가 사진, 타이틀, 지역 관광 정보를 조합해 매거진을 생성합니다.

<br/>

#### 1.4. 기존 서비스 대비 차별성
| 구분 | 기존 여행 정보 앱 | 기존 SNS·기록 앱 | 찌그까 |
|:---:|:---|:---|:---|
| 참여 방식 | 관광 정보 검색 및 열람 | 자유로운 사진 업로드 | 미션 기반 능동적 부산 탐험 |
| 결과물 | 일정표, 리뷰, 장소 정보 | 파편화된 사진 기록 | AI 기반 여행 매거진 자동 생성 |
| 공유 구조 | 공개 리뷰 중심 | 불특정 다수 타임라인 | 동행자 중심 프라이빗 공유 |
| 동기부여 | 포인트 등 외적 보상 | 좋아요, 조회수 경쟁 | 타이틀, 뱃지, 지역 마스터 시스템 |
| 관광 분산 | 인기 장소 중심 노출 | 핫플레이스 중심 확산 | 혼잡도와 미션 보상 기반 수요 분산 |
| 데이터 활용 | 기본 관광 정보 제공 | 제한적 활용 | 미션 검증, 타이틀, 매거진 생성에 직접 활용 |

#### 1.5. 사회적가치 도입 계획
- **관광 수요 분산**: 해운대, 광안리 중심의 관광 수요를 영도, 서구, 사하구, 강서구 등 로컬 지역으로 확장합니다.
- **지역 상권 활성화**: 숨은 명소 주변 카페, 맛집, 문화 공간과 연계한 미션으로 지역 소비를 유도합니다.
- **공공데이터 활용**: 부산시 공공데이터 기반 혼잡도와 방문 패턴을 활용해 관광 정책 수립 근거를 제공합니다.
- **2030 세대 참여 확대**: 부산 여행을 진부한 코스 소비가 아니라 창작 가능한 경험으로 재정의합니다.

### 3. 개발결과

#### 3.1. 전체시스템 흐름도
```text
여행 전
지역 선택 -> 혼잡도 확인 -> 맞춤 미션 선택

여행 중
현장 촬영 -> 사진 업로드 -> AI 사진 분석 -> 미션 검증 -> 개인화 타이틀 획득

여행 후
동행자 반응 수집 -> 방문 기록 정리 -> AI 매거진 생성 -> 동행자 공유
```

<br/>

#### 3.2. 기능설명

##### `지역 탐색 및 혼잡도 지도`
- 부산 관광 스팟을 지도 기반으로 탐색합니다.
- 각 스팟의 혼잡도를 `여유`, `보통`, `혼잡` 3단계 색상으로 표시합니다.
- 사용자는 혼잡도가 낮은 지역을 쉽게 확인하고, 숨은 명소 방문을 선택할 수 있습니다.

##### `장소별 맞춤 사진 미션`
- 장소, 시간대, 계절에 맞는 사진 미션을 제공합니다.
- 예시 미션:
  - 다대포 해수욕장 석양 수평선 중앙 촬영
  - 영도 흰여울문화마을 선박 실루엣 촬영
  - 광안대교 야경 구도 맞추기
- 유명 스팟 미션을 완료하면 인근 숨은 명소가 단계적으로 해금됩니다.

##### `AI 기반 사진 분석 및 미션 검증`
- 사용자가 업로드한 사진을 멀티모달 Vision AI가 분석합니다.
- 피사체, 구도, 색감, 분위기, 장소 맥락을 종합적으로 판단합니다.
- CLIP 기반 텍스트-이미지 유사도, GPS, 촬영 시간을 함께 활용해 미션 달성 여부를 검증합니다.

##### `개인화 타이틀 및 뱃지`
- 미션 결과와 사진 분석 결과를 바탕으로 부산 지역 특화 타이틀을 생성합니다.
- 예시:
  - 영도 골목길 탐험가
  - 다대포 석양을 담은 감성 사진가
  - 광안대교 야경 마스터
- 한 지역의 미션을 연속 완료하면 지역 마스터 타이틀을 획득할 수 있습니다.

##### `동행자 전용 프라이빗 공유`
- 촬영한 미션 사진은 함께 여행한 동행자끼리만 공유됩니다.
- 좋아요, 코멘트, 이모티콘 반응을 통해 부담 없는 피드백을 주고받을 수 있습니다.
- 공개 SNS의 평가 부담을 줄이고, 여행 기록을 함께 즐기는 구조를 제공합니다.

##### `AI 자동 여행 매거진`
- 여행 종료 후 사진, 방문 장소, AI 분석 결과, 타이틀, 뱃지를 조합해 매거진을 자동 생성합니다.
- LLM이 부산 관광지의 역사, 문화적 배경, 사용자의 이동 흐름을 반영해 스토리텔링 문장을 작성합니다.
- 사용자는 별도 편집 없이 완성형 여행 기록물을 얻을 수 있습니다.

#### 3.5. AI 도구 활용
본 프로젝트는 AI를 서비스 핵심 기능과 개발 프로세스 양쪽에서 활용합니다.

- **OpenAI Vision Model**: 미션 사진의 피사체, 구도, 분위기, 장소 맥락을 분석합니다.
- **GPT 기반 LLM**: 방문 장소, 사진 메타데이터, 타이틀을 바탕으로 여행 매거진 본문을 생성합니다.
- **CLIP**: 미션 조건 텍스트와 사용자가 촬영한 사진의 의미적 유사도를 분석해 미션 검증을 보조합니다.
- **Claude Code, OpenAI Codex, GitHub Copilot**: FastAPI API, React Native UI, 상태 관리, Docker 설정, 테스트 코드 등 반복 구현 작업의 초안을 생성하고 리팩토링을 지원합니다.
- **ChatGPT**: DB 스키마, API 설계, 프롬프트 구조, 디버깅 시나리오, README 문서화를 검토하는 데 활용합니다.

AI 도구 활용을 통해 반복 개발 시간을 줄이고, 팀원이 AI 연동 로직과 사용자 경험 설계에 더 집중할 수 있도록 하는 것을 목표로 합니다.

### 4. 설치 및 사용 방법

현재 저장소에는 기획서와 발표자료가 포함되어 있으며, 실제 앱/서버 코드는 향후 추가될 예정입니다. 개발 완료 후 다음 방식으로 실행할 계획입니다.

#### 4.1. Backend
```bash
cd backend
conda activate pnuai
pip install -r requirements.txt
uvicorn app.main:app --reload
```

#### 4.2. Mobile App
```bash
cd apps/mobile
npm install
npm run start
```

#### 4.3. Docker
```bash
docker compose up --build
```
